# Roshab Shahi Portfolio

Premium dependency-free personal portfolio built from the supplied CV.

## Add your profile photo

Put your photo in this folder and name it exactly:

`profile.jpg`

The hero portrait placeholder will automatically be replaced by that image. A vertical portrait works best (roughly 4:5 ratio, e.g. 1200 × 1500 px).

## Run

Open `index.html` directly, or serve the folder with any static server.

## Deploy

This folder can be deployed as-is to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any standard static host.
